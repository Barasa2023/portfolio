ABOUT

Software built with intent, not guesswork.

I'm a software developer based in Kenya, focused on building web applications and backend systems that hold up in production — not just in a demo. My work centers on Python and JavaScript, with an emphasis on clean architecture, dependable APIs, and interfaces that stay out of the user's way.

I care about the parts of software that clients don't always see: how a database is structured, how an API fails gracefully, how a codebase reads six months later. Good software should still make sense to whoever inherits it.

Whether it's a REST API, a data-driven dashboard, or a full web application, I try to start from the actual problem being solved rather than the technology being used to solve it.
